# Security Policy

## Reporting Security Issues

The CloudEvents maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/cloudevents/spec/security/advisories/new) form.

For more details, see the [CloudEvents security policy](https://github.com/cloudevents/spec/blob/main/SECURITY.md).
